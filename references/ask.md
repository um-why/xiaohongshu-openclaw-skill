# 追问模板（输入不足时使用）

> **何时读**：缺关键词/链接、链接类型不明、条数不明等，需要标准话术时再读。缺参时必须先追问，禁止猜测执行。

- 缺关键词：「你想在小红书搜什么？给我一个关键词，例如『露营装备』。」
- 做竞品但目标不明：「是盯某个博主账号，还是按某个关键词看竞品内容？要最新还是高赞？大概看多少条？」
- 缺笔记链接：「请提供笔记链接（explore / discovery/item / xhslink 短链），或 24 位笔记 id。」
- 缺博主链接：「请提供博主主页（xiaohongshu.com/user/profile/…）或 24/29 位 user_id。若只有短链，说明一下是主页还是笔记。」
- 24 位 id 歧义：「这个 id 是一篇笔记，还是一个博主？我好选详情/评论还是作品命令。」
- 短链类型不明：「这条短链是笔记还是博主主页？先确认再查，避免查错。」
- 笔记链接但没说详情还是评论：「这篇笔记你是要看正文和互动，还是要看评论区？」
- 作品条数不明：「要看最近发了什么的话，请告诉我条数（例如 20 或 30）。不写条数时只会返回粉丝等博主信息。」
- 搜索数量：「搜索默认 20 条。需要更多请给具体条数；包月 Token 搜索不要超过 40。」
- 评论数量：「评论默认 10 条。要归纳观点可以加大；包月 Token 评论不要超过 20。」
